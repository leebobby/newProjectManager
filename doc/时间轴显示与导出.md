# 版本时间轴与 WBS A 图显示

版本管理时间轴随页面可用宽度自动排版，窗口大小或侧栏状态变化后重新计算；全部、近三个月、近六个月、近一年和自定义月份区间均使用同一套响应式布局。节点字号保持稳定，密集版本名称优先通过上下分层避让。

主干与分支均使用真实日期比例。每条线画到自身最后一个有效版本日期后收尾，箭头保留五天的视觉余量，标签紧贴箭头右侧；有五个节点的分支无需跟随其他长分支一起延伸。没有版本日期时才使用大版本声明的范围。调整显示不修改版本日期数据。

WBS A 图保留父框包含子框、全部选定层级任务展示和依赖关系切换：

- 舒适展开：每月按 160 像素基础宽度展开，长计划在图内滚动。
- 适应宽度：由后端重新计算时间尺度、嵌套边界和依赖绕行，不缩小字体。长名称本身超出窗口时仍可横向滚动查看全文。
- 缩放：可显式选择 75%、100%、125% 或 150%，预览缩放不改变导出尺寸。
- 顶部日期轴：向下查看任务时持续可见，横向与任务框同步滚动。
- 日期范围：按完整计划确定；今天不在计划窗口中时显示提示，不将历史计划扩展到今天。

`GET /api/wbs/plans/{id}/timeline` 和 `GET /api/wbs/plans/{id}/export.xlsx` 共同支持：

| 参数 | 含义 |
| --- | --- |
| `viewport_width` | 图内可用宽度，整数 320～16000；未传时使用默认舒适展开 |
| `fit_width` | 是否适应窗口，默认 `false` |
| `max_depth` | 展示到第几层，未传时完整展示 |
| `dependency_mode` | `arrows` / `lines` / `hidden` |

页面 SVG、页面 PNG 和 Excel 第三页共用后端布局。Excel 保留最后一次预览的宽度与模式，关闭预览后仍有效，切换 WBS 时重置。切换层级不改变完整计划的日期范围；缩放不裁剪任务。长 PNG 继续按画布尺寸与像素预算降低输出倍率，SVG 保留原始矢量尺寸。
